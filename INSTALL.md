# 📦 Руководство по установке yfetch (Installation Guide)

Это подробное руководство по установке **yfetch** для пользователей **Linux** (с подробными примерами для Arch Linux, Debian, Ubuntu, Fedora и др.) — даже если вы только начинаете знакомство с терминалом!

---

## 1. Системные требования

- **Операционная система:** Любой современный дистрибутив Linux (Arch Linux, Debian, Ubuntu, Fedora, openSUSE, Void, Alpine, NixOS и др.).
- **Python:** версия 3.11 или новее (`python3 --version`).
- **Git:** для загрузки репозитория (`git --version`).
- **Шрифт (рекомендуется):** Nerd Font (например, `ttf-jetbrains-mono-nerd`) для отображения красивых иконок оборудования и дистрибутивов.

---

## 2. Подготовка системы

Перед установкой убедитесь, что в системе установлены базовые утилиты:

**Для Arch Linux / Manjaro / EndeavourOS:**
```bash
sudo pacman -S --needed git python
```

**Для Debian / Ubuntu / Linux Mint:**
```bash
sudo apt update && sudo apt install -y git python3 python3-venv
```

**Для Fedora / RHEL:**
```bash
sudo dnf install -y git python3
```

> **Примечание:** Утилита `lspci` (пакет `pciutils`) опциональна: `yfetch` автоматически использует прямые данные ядра Linux (`/sys/class/drm/`) для обнаружения GPU при отсутствии `lspci`.

---

## 3. Установка yfetch из исходного кода

В современных дистрибутивах Linux действует стандарт **PEP 668** (защита системных пакетов Python). Поэтому наиболее чистым и надёжным способом является установка в изолированное окружение пользователя с созданием исполняемой ссылки в `$PATH`.

### Способ 1: Рекомендуемый (Изолированное окружение + симлинк в PATH)

1. **Клонируйте репозиторий yfetch:**
   ```bash
   git clone https://github.com/itzmidas/yfetch.git ~/yfetch
   cd ~/yfetch
   ```

2. **Создайте окружение и установите yfetch:**
   ```bash
   python3 -m venv ~/.local/share/yfetch/venv
   ~/.local/share/yfetch/venv/bin/pip install .
   ```

3. **Создайте ссылку на исполняемый файл в `~/.local/bin`:**
   ```bash
   mkdir -p ~/.local/bin
   ln -sf ~/.local/share/yfetch/venv/bin/yfetch ~/.local/bin/yfetch
   ```

4. **Проверьте доступность PATH:**
   Если каталог `~/.local/bin` ещё не добавлен в ваш `$PATH`, добавьте его:
   ```bash
   echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
   source ~/.bashrc
   ```
   *(Если вы используете `zsh` вместо `bash`, замените `.bashrc` на `.zshrc`).*

---

### Способ 2: Установка через pipx

Если у вас установлен `pipx`:

```bash
cd ~/yfetch
pipx install .
```

`pipx` автоматически создаст изолированное окружение и сделает команду `yfetch` доступной в вашей системе.

---

### Способ 3: Прямая установка для пользователя

Если вы хотите установить yfetch напрямую в пользовательский каталог:

```bash
cd ~/yfetch
python3 -m pip install --user --break-system-packages .
```

---

## 4. Первый запуск и настройка

После завершения установки запустите yfetch:

```bash
yfetch
```

Программа мгновенно выведет информацию о вашей системе и ASCII-логотип! При первом запуске автоматически генерируется файл настроек:
`~/.config/yfetch/config.toml`

### Интерактивная настройка (TUI)

Чтобы настроить оформление под свой вкус, откройте визуальное меню:

```bash
yfetch --setup
```

В интерактивном конфигураторе:
- Используйте стрелочки **`↑`** и **`↓`** для перемещения между пунктами;
- Нажимайте **`Enter`** для выбора раздела, темы или пресета;
- Нажимайте **`Space`** (Пробел) для включения и выключения модулей информации;
- Изменения сразу же отображаются в окне **Live Preview** справа;
- Нажмите **`s`** для быстрого сохранения конфигурации;
- Нажмите **`Esc`**, чтобы вернуться назад или открыть окно сохранения/выхода.

---

## 5. Добавление собственного ASCII-арта

Хотите использовать свой кастомный логотип?

1. Создайте обычный текстовый файл, например `mylogo.txt`, со своим ASCII рисунком.
2. Скопируйте его в директорию:
   ```bash
   ~/.config/yfetch/ascii/
   ```
3. Запустите `yfetch --setup` и выберите **🖼️ ASCII Art**. Ваш логотип автоматически появится в списке!

## 6. Типичные проблемы и их решения (FAQ)

### Вместо иконок отображаются квадратики или символы `[?]`
- **Причина:** в вашем терминале не установлен шрифт с поддержкой символов Nerd Font.
- **Решение 1:** Установите Nerd Font:
  - Arch: `sudo pacman -S ttf-jetbrains-mono-nerd`
  - Debian/Ubuntu: скачайте и установите любой Nerd Font с [nerdfonts.com](https://www.nerdfonts.com/).
  Затем укажите этот шрифт в настройках эмулятора терминала.
- **Решение 2:** Если вы не хотите устанавливать шрифты, отключите иконки:
  Запустите `yfetch --setup` ➔ перейдите в **🎨 Appearance** ➔ переключите **Nerd Font Icons: OFF**.

### Команда `yfetch: command not found`
- **Причина:** каталог `~/.local/bin` не добавлен в системную переменную `$PATH`.
- **Решение:**
  Выполните:
  ```bash
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
  source ~/.bashrc
  ```

### Цвета выглядят тускло или артефачат
- **Решение:** Убедитесь, что эмулятор терминала поддерживает TrueColor (24-битный цвет). В большинстве современных терминалов (Kitty, Alacritty, Foot, WezTerm, Ghostty, Konsole) TrueColor включён по умолчанию. Убедитесь, что переменная `TERM` установлена корректно (например, `TERM=xterm-256color`).

### Как запускать yfetch при каждом открытии терминала?
- Добавьте команду `yfetch` в конец вашего файла конфигурации оболочки:
  ```bash
  echo "yfetch" >> ~/.bashrc
  ```
  *(или `~/.zshrc` для zsh)*. Благодаря оптимизированной скорости старта yfetch, открытие терминала останется быстрым и отзывчивым!

## 7. Обновление yfetch

Чтобы обновить yfetch до актуальной версии:

```bash
cd ~/yfetch
git pull
~/.local/share/yfetch/venv/bin/pip install --upgrade .
```

Ваши персональные настройки в `~/.config/yfetch/config.toml` и кастомные арты в `~/.config/yfetch/ascii/` сохранятся нетронутыми!

---

## 8. Удаление (Uninstall)

Если вы решите удалить yfetch:

```bash
# 1. Удаление исполняемого файла и изолированного окружения
rm -f ~/.local/bin/yfetch
rm -rf ~/.local/share/yfetch

# 2. (Опционально) Удаление пользовательских настроек и кэша
rm -rf ~/.config/yfetch
```
