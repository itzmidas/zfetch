# 📦 Руководство по установке zfetch (Installation Guide)

Это подробное руководство по установке **zfetch** для пользователей **Arch Linux** — даже если вы только начинаете знакомство с Linux!

---

## 1. Системные требования

- **Операционная система:** Arch Linux (или любой дистрибутив на базе Arch).
- **Python:** версия 3.11 или новее (`python --version`).
- **Git:** для загрузки репозитория (`git --version`).
- **Шрифт (рекомендуется):** Nerd Font (например, `ttf-jetbrains-mono-nerd`) для отображения иконок оборудования и системы.

---

## 2. Подготовка системы

Перед установкой убедитесь, что у вас установлены базовые системные утилиты. Откройте терминал и выполните:

```bash
sudo pacman -S --needed git python pciutils
```

> **Примечание:** пакет `pciutils` содержит утилиту `lspci`, которая используется для быстрого определения модели вашей видеокарты (GPU).

---

## 3. Установка zfetch из исходного кода

В современных версиях Arch Linux действует стандарт **PEP 668** (защита системных пакетов Python). Поэтому наиболее чистым и надёжным способом является установка в пользовательскую изолированную среду с добавлением команды в ваш `$PATH`.

### Способ 1: Рекомендуемый (Изолированное окружение + симлинк в PATH)

1. **Клонируйте репозиторий zfetch:**
   ```bash
   git clone https://github.com/itzmidas/zfetch.git ~/zfetch
   cd ~/zfetch
   ```

2. **Создайте окружение и установите zfetch:**
   ```bash
   python3 -m venv ~/.local/share/zfetch/venv
   ~/.local/share/zfetch/venv/bin/pip install .
   ```

3. **Создайте ссылку на исполняемый файл в `~/.local/bin`:**
   ```bash
   mkdir -p ~/.local/bin
   ln -sf ~/.local/share/zfetch/venv/bin/zfetch ~/.local/bin/zfetch
   ```

4. **Проверьте доступность PATH:**
   Если вы ещё не настраивали `~/.local/bin` в PATH, добавьте его:
   ```bash
   echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
   source ~/.bashrc
   ```
   *(Если вы используете `zsh` вместо `bash`, замените `.bashrc` на `.zshrc`).*

---

### Способ 2: Установка через pipx

Если у вас установлен `pipx` (`sudo pacman -S python-pipx`):

```bash
cd ~/zfetch
pipx install .
```

`pipx` автоматически установит зависимости и сделает команду `zfetch` доступной в вашей системе.

---

### Способ 3: Прямая установка для пользователя

Если вы хотите установить zfetch напрямую в `~/.local`:

```bash
cd ~/zfetch
python3 -m pip install --user --break-system-packages .
```

---

## 4. Первый запуск и настройка

После завершения установки запустите zfetch:

```bash
zfetch
```

Программа мгновенно выведет системную информацию вашего компьютера и стандартный логотип Arch Linux! При первом запуске автоматически создастся файл конфигурации по умолчанию:
`~/.config/zfetch/config.toml`

### Интерактивная настройка (TUI)

Чтобы настроить оформление под свой вкус, откройте графическое меню:

```bash
zfetch --setup
```

В интерактивном конфигураторе:
- Используйте стрелочки **`↑`** и **`↓`** для навигации;
- Нажимайте **`Enter`** для выбора раздела или стиля;
- Нажимайте **`Space`** (Пробел) для включения и выключения информационных модулей;
- Изменения сразу же отображаются в окне **Live Preview** справа;
- Нажмите **`s`** для быстрого сохранения настроек;
- Нажмите **`Esc`**, чтобы вернуться назад или закрыть настройку.

---

## 5. Добавление собственного ASCII-арта

Хотите использовать свой логотип?

1. Создайте текстовый файл, например `mylogo.txt`, с вашим ASCII рисунком.
2. Скопируйте его в каталог:
   ```bash
   ~/.config/zfetch/ascii/
   ```
3. Запустите `zfetch --setup` и перейдите в меню **🖼️ ASCII Art**. Ваш файл появится в списке автоматически!

## 6. Типичные проблемы и их решения (FAQ)

### Вместо иконок отображаются квадратики или вопросительные знаки `[?]`
- **Причина:** в вашем терминале не установлен шрифт с поддержкой символов Nerd Font.
- **Решение 1:** Установите официальный Nerd Font в Arch Linux:
  ```bash
  sudo pacman -S ttf-jetbrains-mono-nerd
  ```
  После установки выберите шрифт `JetBrainsMono Nerd Font` в настройках вашего эмулятора терминала (Alacritty, Kitty, Konsole и др.).
- **Решение 2:** Если вы не хотите ставить дополнительные шрифты, просто отключите иконки:
  Запустите `zfetch --setup` ➔ перейдите в **🎨 Appearance** ➔ переключите **Nerd Font Icons: OFF**.

### Команда `zfetch: command not found`
- **Причина:** каталог `~/.local/bin` не добавлен в системную переменную `$PATH`.
- **Решение:**
  Выполните:
  ```bash
  echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
  source ~/.bashrc
  ```

### Цвета выглядят тускло или артефачат
- **Решение:** Убедитесь, что ваш эмулятор терминала поддерживает TrueColor (24-битный цвет). В подавляющем большинстве современных терминалов (Kitty, Alacritty, Foot, Konsole, WezTerm) TrueColor включён по умолчанию. Убедитесь, что переменная `TERM` установлена корректно (например, `TERM=xterm-256color`).

### Как включить zfetch при каждом открытии терминала?
- Добавьте вызов `zfetch` в конец вашего конфигурационного файла оболочки:
  ```bash
  echo "zfetch" >> ~/.bashrc
  ```
  *(или `~/.zshrc` для zsh)*. Благодаря оптимизированной скорости старта zfetch (< 50мс), открытие терминала останется мгновенным!

## 7. Обновление zfetch

Чтобы обновить zfetch до свежей версии из репозитория:

```bash
cd ~/zfetch
git pull
~/.local/share/zfetch/venv/bin/pip install --upgrade .
```

Ваши настройки в `~/.config/zfetch/config.toml` и пользовательские арты в `~/.config/zfetch/ascii/` сохранятся нетронутыми!

---

## 8. Удаление (Uninstall)

Если вы решите удалить zfetch:

```bash
# 1. Удаление исполняемого файла и виртуального окружения
rm -f ~/.local/bin/zfetch
rm -rf ~/.local/share/zfetch

# 2. (Опционально) Удаление настроек и кэша
rm -rf ~/.config/zfetch
```
